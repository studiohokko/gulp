# 画像 alt 属性 — 依頼テンプレート

**このファイルが判定ルールの正本。** 対象の HTML/PHP を指定すると、AI が `src` のパスから画像ファイルを読み、alt を入力する。

## 使い方

1. 対象の **HTML / PHP**、または **フォルダ** を指定する（開いておいても可）
2. 「**alt入れて**」と言う

画像のアップロードは不要。`get_theme_file_uri('dev/public/assets/img/...')` や `./assets/img/...` を辿って、ディスク上の画像を見る。

ルールは `.cursor/rules/alt-attributes.mdc` 経由で AI が自動参照する。毎回このファイルを全部貼る必要はない。

**ショートカット:** `.md` 編集時にスニペット **`alt-prompt`**（`markdown.json`）

---

フォルダ指定の対象は **配下の `.php` / `.html`**。画像フォルダ（`img/`）自体ではなく、それを参照している HTML/PHP 側の `alt` を書く。
---

## AI の手順

1. 対象を決める
   - ファイル指定 → そのファイル
   - フォルダ指定 / 「このフォルダ全体」→ 配下の `.php` / `.html`
   - 除外: `node_modules` / `vendor` / `.git` / `public/assets/js` / `package-lock.json` 等
   - `<img>` が1つもないファイルはスキップ
2. 各ファイルの `<img>`（`<picture>` 含む）を洗い出す
3. `src` / `srcset` から画像パスを解決し、**ディスク上のファイルを Read して中身を見る**
4. 見出し・本文・ボタン・リンク・figcaption との重複を確認する
5. 判定ルールに従って **alt をファイルへ書き込む**
6. 結果一覧（ファイル / 画像名 / 用途 / alt / 理由）を出す
7. 迷ったもの・パスが辿れないものは **書き込まず**、最後にまとめて確認する（フォルダ一括でも、迷うたびに止めない）

フォルダ一括でも判定は画像ごと。前後関係は **その画像があるファイル単位** で見る。

### パスの解決

| HTML/PHP の書き方 | 見るファイル |
|---|---|
| `get_theme_file_uri('dev/public/assets/img/foo.webp')` | テーマ内 `dev/public/assets/img/foo.webp` |
| `./assets/img/foo.webp`（LP / 静的） | `public/assets/img/foo.webp`（なければ `dev/public/assets/img/`） |
| `<picture>` の PC `source` + SP `img` | **両方**見る。alt は `<img>` にだけ付ける |

優先は公開用の `dev/public/assets/img/`（ページに出る画像）。無ければ `dev/src/assets/img/`。

### 書き込む対象

- **空の alt**（`alt=""` / `alt=''` / 属性なし）を判定して入力する
- すでに意味のある alt があるものは、書き換え指示がなければ触らない
- ACF / メディアライブラリ由来（`$image['alt']` 等）はテンプレートに直書きしない。入れるべき文言だけ報告する
- 外部 URL・ファイル未配置は見られないので、確認待ちにする

---

## 基本方針

HTML の前後関係も考慮した上で、各画像に適切な alt 属性を入力する。

- alt 属性は SEO のためもありますが、**アクセシビリティ（スクリーンリーダー利用者への情報提供）を最優先**に作成する
- SEO キーワードは、不自然にならない範囲で自然に含める
- SEO 目的だけのキーワードの羅列や、不自然な表現は避ける
- 画像から読み取れない内容や推測は書かない
- 「画像」「写真」「イメージ」などの不要な表現は入れない

---

## HTML（PHP）も確認する

画像単体ではなくページ全体の構造を考慮する。以下を確認する。

- 見出し（h1〜h6）と内容が重複していないか
- 本文と内容が重複していないか
- ボタンのテキストと重複していないか
- リンクテキストと重複していないか
- figcaption が存在するか
- 画像がコンテンツ画像なのか装飾画像なのか

画像の前後に同じ内容が記載されている場合は `alt=""` にする。

---

## 判定ルール

### ① 装飾画像

以下に該当する画像は `alt=""` にする。

- 背景画像
- 飾り画像
- デザインパーツ
- 区切り線
- 装飾アイコン

このプロジェクトでは装飾画像に `aria-hidden="true"` も付ける（`coding-guide`）。不足していれば合わせて付ける。

### ② アイコン画像

ボタンやリンクの横に同じ意味のテキストがある場合は `alt=""`。
アイコン単体で意味を持つ場合のみ内容を記述する。

### ③ ロゴ・バナー・見出しなどのテキスト画像

画像内に書かれている文字を、**そのまま** alt にする。意訳しない。

### ④ 前後に同じ情報がある画像

画像の内容が見出しや本文などで既に説明されている場合は `alt=""` にする。

### ⑤ 図・グラフ・表

画像だけでも内容が理解できるように文章化する。

- 割合
- 比較
- 数値
- グラフから読み取れる内容

を分かりやすく記述する。内容が長くなっても省略しない。

### ⑥ 人物・商品・施設・風景などのコンテンツ画像

電話で相手に画像を説明するようなイメージで作成する。
そのページで伝えたい内容が分かるように記述する。
必要に応じて自然な SEO キーワードを含める。

---

## 例

```
----------------------------------------
画像名：sample01.jpg
用途：コンテンツ画像
alt："代表者が会議室で事業計画を説明している様子"
理由：
記事内容を補足する重要な画像のため。
----------------------------------------
画像名：sample02.svg
用途：装飾画像
alt：""
理由：
装飾のみで情報を持たないため。
----------------------------------------
画像名：sample03.png
用途：テキスト画像
alt："会社概要"
理由：
画像内の文字情報をそのまま伝えるため。
----------------------------------------
```

---

## 判断に迷う場合

判断に迷う画像は勝手に決めない。**書き込まず**、次のように理由を添えて確認する。

- 装飾画像の可能性が高い
- 前後に同じ内容があるため alt は不要と思われる
- HTML 全体を見ないと判断できない
- 画像ファイルが見つからない / 外部 URL のため中身を見られない

---

## 最終チェック

入力の最後に、次も確認する。

- `alt=""` にした方が良い画像はないか
- 不要に長すぎる alt になっていないか（⑤の図・グラフは除く）
- SEO 目的だけの文章になっていないか
- スクリーンリーダー利用者に内容が伝わるか
- HTML との内容重複はないか

---

## 書き込み時の注意

- **alt 属性だけ**更新する。HTML 構造・クラス名・他属性は変えない
- `<picture>` の alt は `<img>` にだけ付ける（`<source>` には付けない）
- PHP に直書きするときは `esc_attr()` は、PHP 式の中に入れる場合のみ。静的な文字列なら `alt='...'` でよい（既存のクォートに合わせる）
- 静的 HTML の `alt='会社概要'` のように直書きする
- 依頼されていないファイルは触らない
